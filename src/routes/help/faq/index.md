## Why is my render distance so low even though I increased it?

The render distance is capped by the server. This has been done to improve performance. We suggest using Optifine to make it seem like you have a higher render distance by keeping chunks loaded client side. Optifine can be download from https://optifine.net/downloads. 

## Why does it tell me "Cannot send chat message" when I talk?

You muted yourself. To be able to chat again, hit escape, options, chat settings, and make "Chat: True".

## Why can't I vote?

The most common causes of not being able to vote is

    You voted less than 24 hours ago (or 12 hours in the case of TOPG). You can use /votenext to check when you can vote next.

    You already voted for another server. The vote sites don't let you vote for more than one server each day. Pick your favorite!

    Someone with the same IP address as you already voted today. The vote sites don't let multiple people use the same IP to vote. You can use a VPN/proxy or mobile data to bypass this. 

In order to check if your vote was recieved by Acorn, you can use /votelast which will show you when Acorn last registered your vote. Alternatively, you can use /votenext to see when Acorn thinks you'll be able to vote next. When voting, make sure that you are using your current name in a case sensitive manner. Also check to make sure that the server is online. If you vote while the server is offline or restarting, your votes will not register. 

## Someone griefed me. What should I do?

Stand where the grief occurred and create a /ticket describing the issue. When a mod returns, they can easily fix the grief for you. Do not attempt to repair the grief yourself, and don't remove items from or add items to any of the chests which may have been stolen from. Messing with the surroundings will make it harder for them to fix the grief.
